# SolarCity

Статический сайт SolarCity: адаптивная главная страница, интерактивные схемы, анимации и локальные изображения и видео. Внешние зависимости для сборки не нужны.

## Публикация на Vercel

1. Распакуйте архив.
2. Загрузите содержимое папки `SolarCity-Vercel` в корень Git-репозитория. Файлы `package.json` и `vercel.json`, а также папки `public` и `scripts` должны находиться в корне.
3. Импортируйте этот репозиторий в Vercel и выберите следующие настройки:

| Настройка | Значение |
| --- | --- |
| Framework Preset | Other |
| Root Directory | Корень репозитория |
| Build Command | `npm run build` |
| Output Directory | `dist` |
| Environment Variables | Не требуются |

Параметры сборки уже указаны в `vercel.json`. После импорта нажмите Deploy.

Документация конфигурации: https://vercel.com/docs/project-configuration/vercel-json

## Локальная проверка

Нужен Node.js 20 или новее. Из папки проекта выполните:

```sh
npm run build
```

Готовые файлы появятся в `dist`. Для просмотра запустите любой статический HTTP-сервер с этой папкой в качестве корня. Например, при установленном Python:

```sh
python3 -m http.server 8080 --directory dist
```

Откройте http://localhost:8080.

## Редактирование

- `public/index.html` — содержание страницы.
- `public/styles.css` — оформление и адаптивность.
- `public/script.js` — интерактивность и анимации.
- `public/assets` — используемые изображения и видео.

После изменений повторно выполните сборку или отправьте изменения в подключённый репозиторий.

Форма сейчас проверяет поля и показывает демонстрационное сообщение об успехе; отправка заявок в CRM или на почту ещё не подключена. Переключатель EN оставлен для будущей английской версии. Изображения проектов с отметкой «ІЛЮСТРАЦІЯ» являются иллюстрациями.
