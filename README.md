# SolarCity

Статический сайт SolarCity с украинской и английской версиями. В архиве — актуальные файлы на 20 октября 2026 года: адаптивная главная страница, интерактивные схемы, анимации, изображения и видео. Сборка не требует внешних зависимостей.

## Публикация на Vercel

1. Распакуйте архив.
2. Загрузите **содержимое** папки `SolarCity-Vercel` в корень Git-репозитория. Файлы `package.json` и `vercel.json`, папки `public` и `scripts` должны находиться в корне репозитория.
3. Импортируйте репозиторий в Vercel и используйте следующие настройки:

| Настройка | Значение |
| --- | --- |
| Framework Preset | Other |
| Root Directory | Корень репозитория |
| Build Command | `npm run build` |
| Output Directory | `dist` |
| Environment Variables | Не требуются |

Параметры сборки уже записаны в `vercel.json`. Нажмите **Deploy**.

Если обновляете существующий репозиторий, замените старые файлы этим комплектом. Убедитесь, что старые настройки сборки и дополнительные файлы не попали в новый деплой.

Украинская страница находится по адресу `/`, английская — `/en/`. Переключатель сохраняет место внутри страницы. Восстановление позиции после обновления и переходов по истории работает в текущей вкладке браузера.

## Локальная сборка и просмотр

Нужен Node.js 22 или новее. Из папки проекта выполните:

```sh
npm run build
```

Результат появится в `dist`. Запустите любой статический HTTP-сервер с этой папкой в качестве корня. Например, при установленном Python:

```sh
python3 -m http.server 8080 --directory dist
```

Откройте http://localhost:8080 и http://localhost:8080/en/.

## Файлы проекта

- `public/index.html` — украинская страница.
- `public/en/index.html` — английская страница.
- `public/styles.css` — оформление и адаптивность.
- `public/script.js` — интерактивность и анимации.
- `public/i18n.js` — переводы динамических текстов.
- `public/position.js` — восстановление позиции и переходы между языками.
- `public/assets` — используемые изображения и видео.

После изменений повторно выполните сборку или отправьте файлы в подключённый репозиторий.

## Текущее поведение

Форма проверяет поля и показывает демонстрационное сообщение об успехе. Отправка заявок в CRM или на почту пока не подключена. Ссылка на политику конфиденциальности неактивна. Шильдик HOVER открывает сайт студии в новой вкладке. Изображения проектов с отметкой «ІЛЮСТРАЦІЯ» являются иллюстрациями.
